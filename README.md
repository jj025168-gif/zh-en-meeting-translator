# 中英多人語音翻譯

純 HTML、CSS、JavaScript 的四人逐句翻譯頁面。每人用自己的手機開同一個房間，選擇繁體中文或 English；說完一句後，所有人會看到原文與譯文。主持人的瀏覽器負責翻譯，必要時由 MyMemory 備援。本次只有本機檔案，尚未部署。

## 開房間與邀請

1. 開啟 index.html。手機實際使用時，需先由審查者部署到 HTTPS 網址，Safari 和 Chrome 的麥克風功能才能依裝置規則運作。
2. 主持人輸入名字、選擇自己的語言，按「建立房間」。房間代碼使用瀏覽器加密亂數產生；建立者才會取得主持人身分。
3. 按房間內的「邀請」。支援系統分享的手機會叫出分享選單，其他瀏覽器可複製完整連結。把連結交給另三位與會者。
4. 受邀者開啟連結，輸入名字、選擇語言並按「加入」。每人都要親自按一次建立或加入，讓手機嘗試解鎖後續語音播放。重新整理後也須按畫面上的「點一下繼續」。
5. 主持人可在設定輸入自己的 Claude API 金鑰、模型及常用人名與術語。沒有金鑰時由主持人使用 MyMemory。金鑰只存主持人瀏覽器的本機儲存空間。

## 使用方式

- 按大按鈕說一句，停頓後自動送出；也可再按一次結束。辨識中的文字只顯示在自己的手機。瀏覽器不支援語音辨識時，可按鍵盤圖示打字送出。
- 一次只有一人說話。有人正在聽寫時，其他人的說話按鈕會停用，譯文語音暫停；超過 30 秒沒有結束訊號會自動解除。網路通知有延遲，喇叭尾音仍可能被收進麥克風。
- 每支手機只會自動念出自己需要的譯文：中文使用者聽英文原文的中文譯文，英文使用者聽中文原文的英文譯文。每句只自動念一次；可按對話上的「再念一次」手動重播。
- 房內有多支英文手機時，請只讓一支保持本機播放開啟，其他支用喇叭按鈕關閉，避免同一句英文疊音。關閉本機播放仍會顯示文字，也不影響手動重播。
- 設定可改名字、語言、字體大小、中文與英文聲音及語速、MyMemory 電子郵件；主持人另可設定 Claude 金鑰、模型、補充說明及試譯。
- 對話最多在各自瀏覽器保存最近 300 句。設定內可匯出純文字到剪貼簿，或經確認後清空自己裝置的紀錄。清空不會刪除別人的紀錄或 ntfy 快取。

## 本機測試

直接以電腦瀏覽器開 index.html。先在一般視窗建立房間，再把邀請連結貼到無痕視窗或另一種瀏覽器，分別加入中文與英文身分。兩個普通分頁共用預設設定及歷史儲存空間，不適合驗證身分隔離。電腦上可用打字備援測跨視窗傳送；翻譯及房間連線仍需能連到 ntfy.sh 與 Claude 或 MyMemory。

## 已知限制與隱私

- 晚加入者看不到加入前的對話。離線期間的訊息在 ntfy 快取期限內可於重連時嘗試補收；本機紀錄只在各自瀏覽器。
- 主持人離線時，說話者會等 15 秒再呼叫 MyMemory。MyMemory 的免費額度、網路或翻譯品質可能影響結果。ntfy.sh 也有每日訊息與頻率限制，詳見 NOTES.md。
- 翻譯是逐句完成，無法同步口譯。四支手機的喇叭、收音、語音服務與背景連線效果，需要在實際會議環境檢查。
- 對話文字與名字會經過 ntfy.sh 公開轉送服務，以及 Claude 或 MyMemory 翻譯服務。知道房間連結的人就可能看見對話或冒充成員；請每場會議開新房間，只把連結給與會者。
- 請勿用此頁談薪資、個資、學生資料等敏感內容。主持人不要在共用手機留下 API 金鑰。

## 需要實機測試的項目

1. iPhone Safari 按加入解鎖聲音後，其他手機送來的譯文能否自動念出來；這是最重要的一項。
2. iPhone Safari 與 Android Chrome 的繁體中文 zh-TW、英文 en-US 聽寫及播音。
3. 四支手機同時在線、在同一間會議室的收音、疊音與延遲。
4. 螢幕休眠及切到其他 App 再回來後，連線、補訊息和主持人代翻是否恢復。
5. 四支手機共用公司 Wi-Fi 對外 IP 時，ntfy.sh 發布量及頻率限制對長會議的影響。
6. iPhone Safari 上由 HTTPS 網頁直接使用 ntfy.sh 的 CORS 與 SSE 穩定性。
7. iPhone 說完後約 2 秒自動送出；也要確認手動結束及系統沒有回報結束時的 5 秒保險。
